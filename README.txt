ASHOKAI — LANDING PAGE NFC

UTILISATION
1. Décompressez le ZIP.
2. Ouvrez index.html dans Chrome, Edge, IntelliJ ou VS Code.
Aucune installation npm n’est nécessaire.
3. Pour une carte NFC, hébergez le contenu de ce dossier sur Vercel, Netlify ou un hébergement statique, puis encodez son URL HTTPS sur la carte.
